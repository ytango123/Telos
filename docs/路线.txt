# Telos 开发路线

## 第一期 - MVP（本地优先）✅ 完成

**目标**：验证核心工作流，本地运行，网站作为载体

**技术方案**：
- 前端：Next.js 16 + Tailwind 4 + shadcn/ui
- LLM：DeepSeek V4 Flash（高性价比）
- 数据：SQLite（本地）+ LanceDB（向量）
- 内容渲染：自建 MDX 组件（接入 Fumadocs UI 组件 + Shiki 高亮）

**核心功能**：
- [x] Block 创建界面（问题 + 目标 + 资源附件）
- [x] 异步内容生成流程（含取消、重试）
- [x] 章节化学习工作站展示
- [x] 本地数据持久化
- [x] 附件上传与 RAG 检索
- [x] 丰富内容格式（Shiki 代码高亮、TOC、彩色高亮、文件树、图片缩放）
- [x] 学习页阅读体验优化（右上悬浮目录、左侧目录可收起、正文加宽）

**预估成本**：~$5-20/月（DeepSeek API）

## 当前技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | Next.js 16 (App Router) |
| 样式 | Tailwind CSS 4 + oklch 颜色系统 |
| UI 组件 | shadcn/ui + 自建 Dialog/MaterialPicker |
| 状态管理 | React Query |
| Markdown | react-markdown + KaTeX + Shiki + ImageZoom |
| 后端 | Python FastAPI |
| 数据库 | SQLAlchemy + SQLite |
| 向量存储 | LanceDB |
| LLM | DeepSeek V4 Flash |
| 网络检索 | Tavily Search API |
| URL 解析 | Jina Reader |

## 下一步优先级

1. **Reviewer Agent**：基于 outline 子点 + 卡片引用做章节自检与重写
2. **Chrome 扩展**：用户登录后抓取反爬页面（知乎/小红书等）
3. **图片理解**：接入视觉模型分析图片内容
4. **视频转文字**：whisper 或 API 方案
