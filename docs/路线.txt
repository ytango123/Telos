# Telos 开发路线

## 第一期 - MVP（本地优先）

**目标**：验证核心工作流，本地运行，网站作为载体

**技术方案**：
- 前端：Next.js 15 + Tailwind + shadcn/ui + Lexical
- LLM：DeepSeek V4 Flash（高性价比）
- 数据：SQLite（本地）+ LanceDB（向量）
- Agent：LangGraph 基础编排

**核心功能**：
- [ ] Block 创建界面（问题 + 目标 + 资源附件）
- [ ] 异步内容生成流程
- [ ] 章节化学习工作站展示
- [ ] 本地数据持久化

**预估成本**：~$5-20/月（DeepSeek API）
