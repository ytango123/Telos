# Telos 技术选型文档

## 1. 设计原则

- **成本优先**：初期使用高性价比方案，验证核心流程后再考虑升级
- **本地优先**：第一期数据存储本地，降低基础设施复杂度
- **渐进增强**：MVP 先跑通核心流程，后续迭代增加高级功能

## 3. 技术栈选型

### 3.1 前端

| 模块 | 选型 | 版本 | 理由 |
|------|------|------|------|
| 框架 | **Next.js** | 15+ (App Router) | SSR/SSG、React Server Components、行业标准 |
| 样式 | **Tailwind CSS** | 4.x | 快速开发、易于定制、与 Next.js 深度集成 |
| UI 组件 | **shadcn/ui** | - | 可定制、无运行时依赖、美观现代 |
| 富文本编辑器 | **Lexical** | - | Meta 出品、React 优先、TypeScript 支持好 |
| 图表渲染 | **beautiful-mermaid** | - | Vercel 出品、SSR 兼容、支持动画、专为 AI 场景设计 |
| 数学公式 | **KaTeX** | - | 轻量、渲染快 |
| 代码高亮 | **Shiki** | - | VS Code 主题兼容、SSR 友好 |

### 3.2 后端 / AI 编排

| 模块 | 选型 | 理由 |
|------|------|------|
| 运行时 | **Node.js** 或 **Python** | Node.js 与前端统一；Python 生态更丰富（LangChain/LangGraph） |
| Agent 框架 | **LangGraph** | 图结构编排、支持循环/分支/条件、生产级持久化、126K+ stars |
| 任务队列 | **BullMQ** (Node) 或 **Celery** (Python) | 异步任务处理、进度追踪 |

### 3.3 LLM 模型（成本优先）

| 模型 | 定价 (每百万 Token) | 上下文 | 用途 |
|------|---------------------|--------|------|
| **DeepSeek V4 Flash** | 输入 $0.14 / 输出 $0.28（缓存命中 $0.0028） | 1M | **主力模型**，性价比极高 |
| **DeepSeek V4 Pro** | 输入 $0.435 / 输出 $0.87（75% 折扣至 2026/5/31） | 1M | 复杂推理任务备选 |
| Claude / GPT-4o | 较贵 | 128K-200K | 后期可选升级 |

**选型理由**：
- DeepSeek V4 Flash 成本约为 Claude 的 **1/20**，GPT-4o 的 **1/18**
- 1M 上下文窗口，足够处理长文档
- 支持 Thinking Mode、Tool Calls、JSON Output
- 缓存命中价格极低（$0.0028/M），适合 RAG 场景

**API 配置**：
```
BASE_URL: https://api.deepseek.com
MODEL: deepseek-v4-flash (默认) / deepseek-v4-pro (复杂任务)
```

### 3.4 数据存储（第一期本地优先）

| 模块 | 选型 | 理由 |
|------|------|------|
| 本地数据库 | **SQLite** | 零配置、文件级存储、足够 MVP 使用 |
| ORM | **Drizzle** (Node) 或 **SQLAlchemy** (Python) | 类型安全、轻量 |
| 向量存储 | **LanceDB** 或 **Chroma** | 本地嵌入式向量数据库，无需服务 |
| 文件存储 | 本地文件系统 | 用户上传的 PDF、音视频等 |

**后期扩展**：验证成功后可迁移至 Supabase (PostgreSQL + pgvector)

### 3.5 内容获取 / 爬虫

| 场景 | 选型 | 理由 |
|------|------|------|
| 通用网页 | **Firecrawl** | 自动转 Markdown、去噪、LLM 友好 |
| 复杂 SPA | **Playwright** | 本地运行、免费、处理 JS 渲染页面 |
| 学术搜索 | **Semantic Scholar API** / **arxiv API** | 免费、结构化数据 |

### 3.6 多模态生成

| 内容类型 | 方案 |
|----------|------|
| 流程图/架构图 | LLM 生成 Mermaid 代码 → beautiful-mermaid 渲染 |
| SVG 动画 | LLM 生成 SVG + CSS/SMIL 动画 |
| 代码块 | Shiki 语法高亮 |
| 数学公式 | KaTeX 渲染 |

## 4. 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                        Frontend                             │
│   Next.js 15 + Tailwind + shadcn/ui + Lexical               │
│   (学习工作站 UI、章节导航、交互笔记)                          │
└─────────────────────┬───────────────────────────────────────┘
                      │ API Routes
┌─────────────────────▼───────────────────────────────────────┐
│                   Backend (Next.js API / Python)            │
│   ├── Block/Group CRUD                                      │
│   ├── 任务队列管理                                           │
│   └── 学习内容交付                                           │
└─────────────────────┬───────────────────────────────────────┘
                      │
┌─────────────────────▼───────────────────────────────────────┐
│                  AI Orchestration (LangGraph)               │
│   ├── 检索 Agent (Firecrawl + RAG)                          │
│   ├── 内容生成 Agent (DeepSeek V4)                          │
│   ├── 结构规划 Agent                                        │
│   └── 多模态生成 Agent (图表/动画)                           │
└─────────────────────┬───────────────────────────────────────┘
                      │
┌─────────────────────▼───────────────────────────────────────┐
│                    Data Layer (本地)                         │
│   SQLite (用户数据/Block/课程元数据)                          │
│   LanceDB/Chroma (向量检索)                                  │
│   本地文件系统 (PDF/音视频/生成内容)                          │
└─────────────────────────────────────────────────────────────┘
```

## 5. 开发阶段规划

### Phase 1 - MVP 核心验证
- [ ] Block 创建 + 目标配置 UI
- [ ] DeepSeek 集成 + 基础内容生成
- [ ] 章节化学习站展示
- [ ] 本地数据持久化

### Phase 2 - Agent 能力扩展
- [ ] LangGraph 多 Agent 编排
- [ ] Firecrawl 多源检索
- [ ] RAG 增强 (LanceDB)
- [ ] Mermaid 图表生成

### Phase 3 - 完整体验
- [ ] 交互式笔记/划重点
- [ ] AI 追问对话
- [ ] 内容微调/用户编辑
- [ ] SVG 动画/多模态

### Phase 4 - 规模化（可选）
- [ ] 迁移至云数据库 (Supabase)
- [ ] 升级 LLM (Claude/GPT-4o)
- [ ] 用户系统/多设备同步
